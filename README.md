# 🌿 Botanova – Grow Green. Live Naturally.

Botanova is a modern, responsive plant e-commerce website designed to help plant enthusiasts discover beautiful indoor and outdoor plants. The website provides an elegant and user-friendly experience through dedicated Home, Products, and Contact pages.

The project is built entirely using **HTML5** and **Tailwind CSS**, focusing on responsive layouts, clean UI design, and reusable utility classes without using any JavaScript frameworks.

## ✨ Features

🏠 Responsive Home Page

🌿 Header Section with Featured Plants

🌱 About Botanova Section

⭐ Best Seller Plants Showcase

💬 Customer Reviews Section

📧 Newsletter Subscription

🛍️ Dedicated Products Page

🌵 Wide Collection of Indoor & Outdoor Plants

🌼 Product Cards with Pricing

📞 Contact Page

📝 Responsive Contact Form

📍 Business Contact Information

🧭 Sticky Navigation Bar

📱 Fully Responsive Design

🎨 Clean & Modern UI using Tailwind CSS

⚡ Lightweight and Fast Loading
